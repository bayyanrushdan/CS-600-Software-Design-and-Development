# CS-600-Software-Design-and-Development
Coursework for CS 600: Software Design and Development, covering requirements, performance metrics, KPIs, and development paradigms.

This repository contains my coursework for CS 600: Software Design and Development at Southern New Hampshire University.

The course examines how requirements and development approaches guide software projects. Topics include functional and nonfunctional requirements, performance metrics and key performance indicators (KPIs), and the selection of development paradigms such as Agile, waterfall, spiral, and DevOps.

Course objectives
Evaluate whether performance metrics and KPIs are relevant to project requirements.
Distinguish what a system must do from the conditions under which it must operate.
Recommend a development paradigm based on a project’s needs, resources, and constraints.
